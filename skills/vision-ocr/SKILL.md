# 图片文字提取（OCR）

用 `vision_analyze` 视觉模型提取图片中的文字（比传统 OCR 更能处理复杂版面、代码、表格、手写混合）。

## 用法

1. 拿到图片路径：`desktop_screenshot`（截屏）或用户提供的文件。
2. `vision_analyze`，prompt 按需：
   - 纯文字：`"完整提取图中的所有文字，保留原始换行与排版顺序，不要解释或补全"`
   - 代码/报错：`"提取图中的代码/报错信息，逐字保留，不要修复或格式化"`
   - 表格：`"提取图中的表格内容为 Markdown 表格"`
3. 核对关键内容（数字、路径、命令）——视觉模型偶有识别错误，重要内容提醒用户确认。

## 常用 prompt 模板

| 场景 | prompt |
|---|---|
| 报错截图 | `提取图中的报错信息（错误类型、消息、堆栈）原文，不要修改` |
| 聊天/文档截图 | `提取图中正文文字，保留换行与分段` |
| 设计稿标注 | `提取图中的尺寸、字号、颜色标注（如 12px、#FFFFFF）` |
| 表格截图 | `把图中表格转为 Markdown 表格，保留全部单元格内容` |

## 注意

- 图片模糊/倾斜会降低准确率；建议原图（`desktop_screenshot` 截图前可放大）。
- 长图超出视觉模型分辨率限制时，裁成多张分别提取再拼接。
- 涉及密钥/口令等敏感文字，提醒用户确认是否真的需要提取。
