# 前端界面审查（截屏 → 分析 → 修复 → 复验）

主模型（DeepSeek）无视觉输入，本流程用 `desktop_screenshot` 截屏 + `vision_analyze` 交给视觉模型分析。

## 流程

1. **截屏**：`desktop_screenshot` → 得到 PNG 路径。
2. **视觉分析**：`vision_analyze`，prompt 明确要求，例如：
   - "识别图中前端界面：列出页面元素与布局结构"
   - "指出样式问题：对齐/间距/颜色/字体/响应式断点/溢出/重叠"
   - "指出交互问题：按钮状态、表单校验、hover/焦点态"
   - "给出具体修复建议（对应 CSS/组件层面）"
3. **定位代码**：结合分析结论用 `semantic_search`（类名/组件名/样式关键词）找到对应源文件；`git_status`/`git_diff` 看是否改动过。
4. **修复**：按建议改代码（必要时先 `checkpoint_create`）。
5. **复验**：重新 `desktop_screenshot` + `vision_analyze` 对比，确认问题消失、无新问题。
6. **交付**：输出 问题清单（截图位置 → 根因 → 修复 → 复验结果），必要时 `changeset_review` 整理改动。

## 分析 prompt 模板（可复用）

```
这是一张前端界面截图。请：
1) 识别页面结构（导航/内容/侧栏/弹层等）与关键元素；
2) 指出视觉与布局问题（对齐、间距、颜色对比、溢出、重叠、响应式断点、字体大小）；
3) 指出交互问题（状态缺失、可点击性、可访问性）；
4) 按优先级给出具体修复建议（指明对应 CSS/组件）。
```

## 注意

- 截图若含敏感信息（账号页等），提示用户或先打码。
- 视觉模型结果可能有误（幻觉），涉及关键改动要结合代码核实。
- 多视图/多状态场景：分别截屏逐张分析（如桌面/移动端、hover/错误态）。
